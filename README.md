# Image Processing (Pengolahan Citra Digital)

Kumpulan tugas praktik pengolahan citra digital (PCD) yang mencakup akuisisi citra, filtering spasial, dan operasi morfologi menggunakan Python.

## Isi Repository
- `PCD_Assignment01_Image_Acquisition.ipynb` — akuisisi dan manipulasi dasar citra digital.
- `PCD_Assignment02_Spatial_Filtering.ipynb` — implementasi filtering spasial (smoothing, sharpening, edge detection).
- `PCD_Assignment03_Morphological_Processing.ipynb` — operasi morfologi citra (erosi, dilasi, opening, closing).
- `blood.png`, `cr.jpeg`, `nature.jpeg`, `town.jpg` — citra contoh yang digunakan dalam eksperimen.

## Cara Menjalankan
1. Pastikan Python, Jupyter, serta library `opencv-python`, `numpy`, dan `matplotlib` sudah terinstal.
2. Buka masing-masing notebook sesuai topik yang ingin dipelajari.
3. Jalankan seluruh sel untuk melihat hasil pemrosesan citra pada gambar contoh yang disediakan.
